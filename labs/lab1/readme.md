## System Specification
CPU brand/model/cores: Tntel Core i7 240H, 10 physical cores, 16 logical processors
Total RAM & type: 16GB

\- Which process is using the most resources and why might that be?
The web browser usually eats up the most CPU and RAM stuff. If I open tons of browser tabs together with my code editor, things start to lag. Each tab loads images, scripts and web content, all of that takes plenty of memory to get you by. 

\- What would happen if your OS didn't manage memory automatically?
Programs would mess up each other’s memory space. When I run many apps at once, RAM can run out. The Windows OS uses hard drive space as extra virtual memory in that case, and everything gets super slow. Without automatic memory management, I would need to manually assign memory for every single program, that would be really messy.

\- How does your OS protect you from security threats?
My operating system keeps different programs separated from one another. It limits what each app can access. It also applies system updates to patch known security holes. User account permissions stop random programs from modifying important system files without my approval.
